DBMuxDevelopment database gateway

Connect your agents. Keep your credentials.

Database passwords stay encrypted on this server. Developers receive scoped, revocable MCP tokens.

Connections

Use dedicated application accounts on development databases.

Add or edit connection

After saving, test the connection, then enable MCP. Editing requires host/service/user fields again; stored passwords are never returned.

Developer tokens

Create one token per developer. Tokens appear once; revocation does not change database passwords.
